zlib / send to kindle

Send books to Kindle.

Mail a local file to your Kindle address through your SMTP server. A Z-Library login is not required.

$zlib kindle send ./dune.epub

Set up once

Install zlib, then complete these steps.

  1. Configure the addresses and SMTP server

    Run zlib kindle. Enter your Kindle address, sender address, SMTP host, and port. The settings are saved in ~/.config/zlib/kindle.json.

    $ zlib kindle

  Kindle address   you@kindle.com
  From address     you@gmail.com
  SMTP host        smtp.gmail.com
  SMTP port        587

  2. Set the SMTP password

    Edit ~/.config/zlib/.env and add ZLIB_SMTP_PWD=your-app-password. For Gmail, use an App Password.

    Keep the password out of command history. zlib reads it when sending and does not write it to kindle.json.

  3. Approve the sender in Amazon

    Open Manage Your Content and Devices → Preferences → Personal Document Settings. Find your Kindle address and add the sender to the approved email list.

Send a file after setup:

$ zlib kindle send ./dune.epub

Send after downloading

Use an ID from your search results. --send-to-kindle sends the file when the download finishes.

$ zlib download 11735659:7659fb --send-to-kindle

For the interactive picker, run zlib search --send-to-kindle. To re-download from history, use zlib history --download ID --send-to-kindle.

Files accepted by zlib

EPUB, PDF, TXT, DOC, DOCX, HTML/HTM, RTF, JPG/JPEG, PNG, BMP, GIF. Convert other formats before sending.

zlib rejects files over 200 MB. For Gmail hosts it also checks the estimated encoded message against 25 MB. Your provider may impose a lower limit.

If sending fails

Sent successfully, but the book has not arrived.

Check the Kindle address and Amazon's approved-sender list. SMTP success means the mail server accepted the message; it does not confirm Kindle delivery.

SMTP rejects the password.

Check the sender and ZLIB_SMTP_PWD. For Gmail, use an App Password. A working-directory .env can override the global file.

The connection times out.

Check the SMTP host, port, and network. ZLIB_PROXY applies to library requests, not SMTP.
