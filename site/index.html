/plugin marketplace add heartleo/zlib

$ zlib doctor

Automatic endpoints. Diagnostics when needed. 自动连接，失败时再排查。

New logins use EAPI first and select endpoints automatically. Use endpoint to inspect the current choice, or doctor to check connectivity. 新登录优先 EAPI，自动选择 endpoint。用 endpoint 查看当前选择，连接失败时用 doctor 排查。

--domain or ZLIB_DOMAIN pins the endpoint and stops automatic switching.--domain 或 ZLIB_DOMAIN 会固定 endpoint，禁用自动换站。

Endpoint and fallback rules连接与兜底规则→
zlib doctor

Sample checks, not live endpoint status.探测示例，不代表当前可用状态。
